# 📚 Livraria 

Este é um projeto simples desenvolvido em **Python** com o objetivo de praticar a manipulação de estruturas de dados básicas e a utilização da biblioteca **Pandas** para exportação de dados para o formato CSV.

## 🚀 Tecnologias Utilizadas

* **Python 3.x**
* **Pandas** (Biblioteca para manipulação e análise de dados)
